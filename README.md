# 📖 研词助手 · 考研英语一词汇工作台

> 一个**本地离线运行**的考研英语一词汇「查看 · 识别 · 记忆」工具。
> 所有文件（PDF / Word / TXT / 图片）都以**查看器方式**打开、按原本排版展示；**按住左键拖拽框选任意区域即识别文字**，识别结果中的单词可点击查看**适用于考研英语一的释义**并标黄、收录；内置考研大纲 5530 词（含词频）+ 红宝书补充词的**英中双向词典**，记忆区支持导出 / 导入 **Word / PDF** 与**词群一键整理**。

---

## ✨ 功能总览

### 🖥 工作区（查看 + 框选识别）
| 能力 | 说明 |
|---|---|
| 统一查看器 | PDF 逐页渲染原版面；Word/TXT 转为排版画布（换行、目录点线对齐、行内空格全保留）；多张照片按上传顺序**拼接成一张长图**（间距可调灰条） |
| 框选识别 | **按住左键约 0.4 秒后拖拽框选任意区域 → 本地 OCR 识别**（引擎内置、完全离线），结果以「已识别」覆盖框显示在原位置 |
| 识别框交互 | 框内单词单击→原形 + 考研释义 + 词群释义并标黄；长按拖选词组；「收录全部」整段录入 |
| 大文件体验 | 文本/Word 秒开、滚动零等待；PDF 采用「低清速览缩略图 + 高清按需渲染」：**拖进度条到哪里就显示哪里**（后台预生成速览图，最近页优先渲染、远处渲染任务自动取消） |
| 界面 | 左右侧栏可拖宽（内容随之缩放）可收起；页面显示缩放 12–40px；超大 PDF 可选页码范围 |

### 📚 记忆区（收录的单词与释义）
- 按收录顺序一行一条（单词 + 释义 + 序号），点击可直接编辑；**动词自动展示时态变化、形容词展示比较级/最高级**
- 搜索、列表区缩放、删除、清空；**🔀 词群整理**（指定单词 / 一键，可选定插入位置）
- **导出 / 导入 Word、PDF**（格式互通，顺序一致）

### 📖 词典（英中双向）
- 英文查中文（考研释义 + 音标 + 词形变化 + 词群释义，成员可点击切换查询、一键收录）；中文反查英文单词
- 顶栏「词库来源」可切换：**内置考研词库（离线）** / **有道词典（在线，自动兜底必应）**
- 模糊命中：不规则变化（is→be）、复数/时态（candidates→candidate）、连字符（well-being→wellbeing）等自动还原

## ⬇️ 下载与使用（推荐方式：Releases）

1. 打开本页右侧 **Releases**，下载最新版压缩包（已内置**全部**运行文件、词库、字体与 OCR 引擎，无需额外下载任何东西）
2. 解压到任意目录（目录名含中文没问题）
3. **Windows**：双击 **`启动.bat`**，浏览器会自动打开 `http://127.0.0.1:8765/`
4. 开始使用：上传资料 → 框选识别 → 点词查义/收录 → 记忆区背诵/导出

> 也可以直接 `git clone` 本仓库后按同样方式运行。

## 🔧 下载注意事项与环境依赖

- **运行环境（二选一，装一个即可）**：
  - **Node.js 18 及以上**（推荐）→ 官网 https://nodejs.org/zh-cn
  - **Python 3.8 及以上**
  - `启动.bat` 会自动检测：优先 Node，找不到则用 Python
- **浏览器**：Chrome / Edge / Firefox（推荐 Chromium 内核）
- **端口 8765**：启动时占用该端口；若被占用，请修改 `server.js` 与 `启动.bat` 中的端口号后再启动
- **安全软件**：首次运行如遇 360 / Defender 对 `启动.bat` / `server.js` 弹窗提示，选择**允许**——脚本只在本机启动本地 HTTP 服务（仅监听 127.0.0.1），不会联网上传你的任何数据
- **联网说明**：词库、OCR、字体全部内置，**断网可正常使用全部核心功能**；仅「在线词典」一项需要联网
- **数据存储**：记忆区与设置保存在浏览器 localStorage（仅本机）。清理浏览器数据/换电脑会丢失记录——重要内容请先「导出 Word / PDF」备份，或使用记忆区「导入」功能迁移
- **识别效果**：框选区域越贴合文字、版面越清晰识别越准；放大页面后再框选小字效果更好。识别在**本地**进行（无网络传输）
- **安装后无法打开**：请确认已装 Node/Python；确认端口未占用；确认解压完整

## 🚀 使用速览

| 想做… | 怎么做 |
|---|---|
| 查资料里的生词 | 上传 → 长按拖拽框选该段 → 识别框内点单词 → 右侧面板看释义 → 📥 收录 |
| 划整句/词组 | 识别框内长按拖选多个单词 |
| 背单词 | 记忆区可编辑 → 导出 Word/PDF 打印；或 🔀 词群整理后成组记忆 |
| 随手查词 | 词典页输入英文或中文，回车；在线不满意切离线（反之亦然） |

## 📁 项目结构

```
研词助手（压缩包根目录）/
├── 启动.bat        # Windows 一键启动（自动检测 Node/Python 并打开浏览器）
├── server.js       # 本地服务（Node 版）：静态文件 + 在线词典多源代理
├── server.py       # 本地服务（Python 备用版）
├── 使用说明.md      # 详细中文说明
└── www/            # 前端 + 全部内置资源
    ├── index.html
    ├── css/style.css
    ├── js/         # 应用逻辑 + 内置考研词库(wordlist.js)
    ├── libs/       # pdf.js / mammoth / pdf-lib / docx / tesseract.js 等（本地离线）
    ├── fonts/      # Noto Sans CJK 中文字体（PDF 导出用）
    └── tessdata/   # 中英文 OCR 识别模型
```
