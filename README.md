# 📖 研词助手 · 考研英语一词汇工作台

> 一个**本地离线运行**的考研英语一词汇「查看 · 识别 · 记忆」工具。
> 上传 **PDF / Word / TXT / 扫描版 PDF / 照片**，把里面的英文变成**可点击的单词**：单击查看**适用于考研英语一的释义**并标黄，长按拖拽框选词组或图片文字区域，一键收录进记忆区；内置考研大纲 5530 词（含词频）+ 红宝书补充词，英中双向查询，可随时导出 / 导入 **Word / PDF**，还可按词族一键整理。

---

## ✨ 功能总览

### 🖥 工作区（识别上传资料中的单词）
| 能力 | 说明 |
|---|---|
| 上传格式 | PDF、DOCX/DOC、TXT/MD、图片（jpg/png/webp/bmp/gif），单文件 ≤ 1GB，可多选、可拖拽、多文档切换；超大 PDF 可选页码范围 |
| 文本模式 | 英文自动变成可点击单词：**单击**→右侧面板弹出原形 + 考研释义 + 词群释义并**标黄**；**长按拖拽**框选多个单词识别**词组** |
| 扫描/图片模式 | 扫描版 PDF 或照片逐页以高清图片显示（懒加载、自动释放内存），**长按拖拽框选任意区域即 OCR 识别**（引擎内置、完全离线），识别框内单词同样可点击查义/标黄/收录、长按拖选词组 |
| 界面 | 左右侧栏可**拖动调宽（内容随之缩放）**、可收起；阅读区 12–40px 缩放；文本选择模式方便复制 |

### 📚 记忆区（收录的单词与释义）
- 按收录顺序一行一条（单词 + 释义 + 序号），点击可直接编辑；**动词自动展示时态变化、形容词展示比较级/最高级**（名词不显示）
- 支持搜索、只对列表区域缩放、删除、清空
- **🔀 词群整理**：指定单词整理（输入单词 → 找出记忆区词群成员 → 插入到所选单词之后或指定序号之后）/ 一键整理（全范围或序号范围自动把词群相邻分组）
- **导出 / 导入**：Word(.docx) 与 PDF（内置中文字体），顺序与记忆区一致，**格式互通**（导出的文件可直接导入回记忆区）

### 🔍 词典（英中双向）
- 英文查中文、中文反查英文，支持**在线 + 离线**双词库（顶栏切换）
- 离线：考研大纲 5530 词 + 红宝书补充词 7600+ 词条，无需联网
- 在线：**有道词典 → 必应词典自动兜底**，任一可用即出结果
- 查询卡片显示查询词本身（如 amazing），原形为辅助信息；附**词形变化**与**词群释义**（可点击切换查询 / 一键收录）
- 模糊命中：不规则变化（is→be）、复数/时态（candidates→candidate）、连字符（well-being→wellbeing）等自动还原

## ⬇️ 下载与使用（推荐方式：Releases）

1. 打开本页右侧 **Releases**，下载最新版压缩包（已内置**全部**运行文件、词库、字体与 OCR 引擎，无需额外下载任何东西）
2. 解压到任意目录（目录名含中文没问题）
3. **Windows**：双击 **`启动.bat`**，浏览器会自动打开 `http://127.0.0.1:8765/`
4. 开始使用：上传资料 → 单击查词 → 收录 → 记忆区背诵/导出

> 也可以直接 `git clone` 本仓库后按同样方式运行。

## 🔧 下载注意事项与环境依赖

- **运行环境（二选一，装一个即可）**：
  - **Node.js 18 及以上**（推荐）→ 官网 https://nodejs.org/zh-cn
  - **Python 3.8 及以上**
  - `启动.bat` 会自动检测：优先 Node，找不到则用 Python
- **浏览器**：Chrome / Edge / Firefox（推荐 Chromium 内核）
- **端口 8765**：启动时占用该端口；若被占用，请修改 `server.js` 与 `启动.bat` 中的端口号后再启动
- **安全软件**：首次运行如遇 360 / Defender 对 `启动.bat` / `server.js` 弹窗提示，选择**允许**——脚本只在本机启动本地 HTTP 服务（仅监听 127.0.0.1），不会联网上传你的任何数据
- **联网说明**：词库、OCR、字体全部内置，**断网可正常使用全部核心功能**；仅「在线词典」一项需要联网
- **数据存储**：记忆区与设置保存在浏览器 localStorage（仅本机）。清理浏览器数据/换电脑会丢失记录——重要内容请先「导出 Word / PDF」备份，或使用记忆区「导入」功能迁移
- **扫描版 PDF / 照片 OCR**：印刷清晰的文字识别效果好；框选区域越贴合文字越准。识别在**本地**进行（无网络传输），速度受电脑 CPU 影响，小区域通常 1–3 秒
- **安装后无法打开**：请确认已装 Node/Python；确认端口未占用；确认解压完整（对比 Releases 页面标注的文件数/体积）

## 🚀 使用速览

| 想做… | 怎么做 |
|---|---|
| 查资料里的生词 | 工作区上传 → 单击该单词 → 右侧面板看释义 → 📥 收录 |
| 划整句/词组 | 文本模式长按拖拽框选；扫描/图片模式长按拖拽框选文字区域，OCR 后即可点词 |
| 背单词 | 记忆区可编辑释义 → 导出 Word/PDF 打印；或 🔀 词群整理后成组记忆 |
| 随手查词 | 词典页输入英文或中文，回车；在线不满意切离线（反之亦然） |

## 📁 项目结构

```
研词助手（压缩包根目录）/
├── 启动.bat        # Windows 一键启动（自动检测 Node/Python 并打开浏览器）
├── server.js       # 本地服务（Node 版）：静态文件 + 在线词典多源代理
├── server.py       # 本地服务（Python 备用版）
├── 使用说明.md      # 详细中文说明
└── www/            # 前端 + 全部内置资源
    ├── index.html
    ├── css/style.css
    ├── js/         # 应用逻辑 + 内置考研词库(wordlist.js)
    ├── libs/       # pdf.js / mammoth / pdf-lib / docx / tesseract.js 等（本地离线）
    ├── fonts/      # Noto Sans CJK 中文字体（PDF 导出用）
    └── tessdata/   # 中英文 OCR 识别模型
```
