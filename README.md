# 📖 研词助手 · 考研英语一词汇工作台

> 一个**本地离线运行**的考研英语一词汇「查看 · 识别 · 记忆」桌面工具（Windows）。
> 所有文件（PDF / Word / TXT / 图片）都以**查看器方式**打开、按原本排版展示；**按住左键拖拽框选任意区域即识别文字**，识别结果中的单词可点击查看**适用于考研英语一的释义**并标黄、收录；内置考研大纲 5530 词（含词频）+ 红宝书补充词的**英中双向词典**，记忆区支持导出 / 导入 **Word / PDF** 与**词群一键整理**。
> 词库、字体、OCR 引擎**全部内置**，无需联网即可使用全部核心功能（仅「在线词典」需要联网）。

---

## ⬇️ 下载与安装

### 方式一：Windows 安装版（推荐）

1. 打开 [Releases 页面](https://github.com/IKTNF/YanWords/releases)，下载最新版 **`YanCi-KaoYan-Vocab-Workbench-*-setup.exe`**
2. 双击运行安装程序（默认简体中文界面，可自选安装目录）
3. 安装完成后，**桌面自动出现「研词助手」快捷方式**（开始菜单同步创建），双击即可使用
4. 应用内置运行环境、词库、中文字体与 OCR 引擎，**无需安装 Node / Python / 浏览器**

> 卸载方式：Windows「设置 → 应用」中找到「研词助手」卸载，或运行安装目录下的 `Uninstall 研词助手.exe`。

### 方式二：绿色便携版（免安装）

- 下载 **`YanCi-KaoYan-Vocab-Workbench-*-portable.exe`**，双击即用。
- 不写注册表、不改系统、不创建快捷方式，适合放在 U 盘或任意目录随身携带。

### 方式三：源码运行（开发者 / 高级用户）

```bash
git clone https://github.com/IKTNF/YanWords.git
cd YanWords
npm install
npm start        # 需要 Node.js 18+
```

> `npm start` 直接以桌面窗口运行；发布构建使用 `npm run dist`（产出安装版 + 便携版）。

## ✨ 功能总览

### 🖥 工作区（查看 + 框选识别）
| 能力 | 说明 |
|---|---|
| 统一查看器 | PDF 逐页渲染原版面；Word/TXT 转为排版画布（换行、目录点线对齐、行内空格全保留）；多张照片按上传顺序**拼接成一张长图**（间距可调灰条） |
| 框选识别 | **按住左键约 0.4 秒后拖拽框选任意区域 → 本地 OCR 识别**（引擎内置、完全离线），结果以「已识别」覆盖框显示在原位置 |
| 识别框交互 | 框内单词单击→原形 + 考研释义 + 词群释义并标黄；长按拖选词组；「收录全部」整段录入 |
| 大文件体验 | 文本/Word 秒开、滚动零等待；PDF 采用「低清速览缩略图 + 高清按需渲染」：**拖进度条到哪里就显示哪里**（缩略图围绕视口滑窗生成、缓存有上限），最近页优先渲染、远处渲染任务自动取消 |
| 界面 | 左右侧栏可拖宽（内容随之缩放）可收起；页面显示缩放 12–40px；超大 PDF 可选页码范围 |

### 📚 记忆区（收录的单词与释义）
- 按收录顺序一行一条（单词 + 释义 + 序号），点击可直接编辑；**动词自动展示时态变化、形容词展示比较级/最高级**
- 搜索、列表区缩放、删除、清空；**🔀 词群整理**（指定单词 / 一键，可选定插入位置）
- **导出 / 导入 Word、PDF**（格式互通，顺序一致）

### 📖 词典（英中双向）
- 英文查中文（考研释义 + 音标 + 词形变化 + 词群释义，成员可点击切换查询、一键收录）；中文反查英文单词
- 顶栏「词库来源」可切换：**内置考研词库（离线）** / **有道词典（在线，自动兜底必应）**
- 模糊命中：不规则变化（is→be）、复数/时态（candidates→candidate）、连字符（well-being→wellbeing）等自动还原

## 🔧 使用说明与注意事项

- **数据存储**：记忆区与设置保存在应用本地（Electron 用户数据目录），仅本机。重装/换电脑会丢失记录——重要内容请先「导出 Word / PDF」备份，或使用记忆区「导入」功能迁移
- **安全软件**：程序为本地应用，首次运行如遇 360 / Defender 提示，选择**允许**。应用只在 `127.0.0.1:8765` 监听本地回环地址，不联网上传你的任何数据
- **联网说明**：词库、OCR、字体全部内置，**断网可正常使用全部核心功能**；仅「在线词典」一项需要联网
- **识别效果**：框选区域越贴合文字、版面越清晰识别越准；放大页面后再框选小字效果更好。识别在**本地**进行（无网络传输）
- **旧版 .doc 解析失败**：先用 WPS / Word 另存为 `.docx` 再上传
- **端口 8765 被占用**（仅源码运行模式会遇到）：关闭占用该端口的程序，或修改 `server.js` 中的端口号

## 📁 项目结构

```
YanWords/
├── main.js               # Electron 主进程：内嵌本地服务 + MuPDF 按路径解析渲染桥接
├── preload.js            # 预加载：文件磁盘路径 / PDF 渲染 IPC
├── package.json          # electron-builder 配置（NSIS 安装版 + 便携版）
├── scripts/prepack.js    # 打包前把 www 与 server 复制进 approot（打进 asar）
├── server.js             # 内嵌本地服务：静态文件 + 在线词典多源代理
├── 使用说明.md            # 详细中文说明（随应用内置）
└── www/                  # 前端 UI + 全部内置资源
    ├── index.html
    ├── css/style.css
    ├── js/               # app / workspace / memory / dictionary / export / wordlist(内置词库)
    ├── libs/             # pdf.js / mammoth / pdf-lib / docx / tesseract.js 等（按需加载，本地离线）
    ├── fonts/            # Noto Sans CJK 中文字体（PDF 导出用）
    └── tessdata/         # 中英文 OCR 识别模型
```
